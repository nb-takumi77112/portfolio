## 概要

ジム出店やエリアマーケティングを担う事業者が、勘や経験だけに頼らず、データに基づいて出店候補地を検討できるようにするためのシステムです。全国約12万件のフィットネス施設を、e-Stat の人口統計と組み合わせて地図上に可視化します。技術スタックの選定から、フロントエンド・バックエンド・インフラまで一貫して担当しました。

## 技術的な課題

- 自然言語で入力された検索条件を OpenAI で構造化データ（JSON）に変換し、施設データ・人口統計・設備条件を組み合わせて検索する流れの設計
- 地図上に大量の施設を表示するときの負荷対策と、人口統計 API のメッシュコード算出・まとめ取得による API 呼び出し回数の抑制
- 料金プラン（standard／premium）ごとの API 機能の出し分けと、管理画面とユーザー向け API の認証方式の分離

## 担当したこと

- Vue 3 + TypeScript + Google Maps による地図画面。半径別の人口集計、月商ポテンシャルの算出、調査報告書の PDF 出力を実装
- Laravel 12 による API 設計（Repository 層）。施設の登録・CSV 取り込み・住所からの位置変換・周辺施設情報の API を提供
- 約12万件の施設データの一括取り込みとメッシュ集計のバッチを Go で実装し、Laravel の API と分けて運用
- 「意図の解析 → データ取得 → 回答の生成」を順に行う AI アシスタントを、サーバー側で処理を束ねる形で設計・実装
- Twig + Tailwind CSS 4 + Alpine.js による管理画面、GitHub Actions から EC2 への自動デプロイ

## 成果

約12万件の施設データを扱う分析基盤を構築し、候補地の商圏人口と競合の密度をひと目で把握できるようにしました。現在はステージング環境で検証中で、リリースの準備を進めています。
