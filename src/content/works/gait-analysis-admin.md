## 概要

リハビリに取り組む患者の歩行状態を、理学療法士が客観的なデータで振り返れるようにするシステムです。モバイルアプリで記録した歩行の計測データを、医療機関の管理者が Web の管理画面で閲覧・運用します。管理者向けのフロントエンドと、AWS Lambda（Python）による REST API を担当しました。

## 技術的な課題

- 管理者用・理学療法士用の 2 系統のユーザープールによるテナント分離と、JWT 検証による認可設計
- DynamoDB のクエリ制限の中で、1,000 件を超える計測データ一覧のページ送りと件数集計を効率化する
- S3 上の歩行動画を一時的な署名付き URL で取得し、グラフと動画の再生位置を同期させる画面

## 担当したこと

- 医療機関の管理者向け画面（理学療法士・患者の管理、計測一覧・推移比較）と BFF の実装
- Cognito を使った認証基盤（サインアップ・ログイン・Cookie によるルート保護・トークン再取得）
- Python Lambda 30 関数超の CRUD API と、理学療法士アカウントの自動発行
- 計測データの登録時に AI 推論を非同期で起動し、結果をまとめて反映する処理の設計
- 関節角度・股関節の累積負荷の可視化と、最大 7 件の計測推移の比較画面

## 成果

担当した管理システムの開発・納品を完了しました。医療機関に求められるセキュリティ・権限の要件を満たす管理基盤を構築しました。
