## 概要

配送事業者の運用担当者が、各拠点から届く荷物の状態更新を一覧で確認できず、問い合わせ対応に時間がかかっていた課題を解決するための API です。配送イベントを受け付け、集計して提供します。

## 技術的な課題

- 拠点ごとに形式もタイミングも違うイベントの、重複や順序の入れ替わりへの対処
- ピーク時の大量リクエストでも応答時間を保つための、並行処理とキャッシュの設計
- 荷物単位の履歴と、拠点・日別の集計という、異なる参照のされ方の両立

## 担当したこと

- Go（chi）によるイベント受付 API・荷物状況照会 API の設計・実装
- goroutine とワーカープールによる並行処理、Redis による照会結果のキャッシュ
- PostgreSQL のテーブル設計（sqlc）と、拠点・日別の集計バッチ
- Cloud Run へのデプロイ構成、Pub/Sub によるイベント連携、負荷試験と計測

## 成果

本番稼働中です。荷物の最新状況をすぐ確認できるようにし、運用担当者の状況確認と問い合わせ対応の手間を減らしました。
