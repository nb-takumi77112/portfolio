## 概要

スキルの依頼者と受注者が安心して取引を終えられるよう、案件の募集・応募、メッセージ、決済、レビュー、売上管理までを一貫して提供するマッチングサービスです。双方の資金を守る Stripe Connect によるマーケットプレイス型決済の設計・実装を中心に担当しました。

## 技術的な課題

- 決済の仮売上・確定、24 時間以内のキャンセル期限、送金方式の使い分けを整合させる必要があった
- 募集型・依頼型で売り手と買い手の役割が入れ替わる取引で、注文の状態遷移と検収・返金の条件を一貫して制御する設計
- ログイン・会員情報変更時のメールによる二段階認証を、既存のメール認証と共存させる設計

## 担当したこと

- Stripe の決済 API と Webhook を設計し、決済・確定・返金・アカウント連携を構築
- 期限切れの決済の自動確定と週次送金のバッチ、残高の同期
- Laravel + Vue による案件一覧・注文詳細・マイページなどの画面と、カード登録・決済画面
- カテゴリ・タグ・レビュー・フォローなどのマッチング機能と管理画面
- メール認証・二段階認証・キューによるメールの非同期送信

## 成果

決済・売上管理・二段階認証を含むすべての機能の実装を完了しました。
